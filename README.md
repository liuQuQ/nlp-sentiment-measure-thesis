## 一、研究简介

本文严格遵循 **NLP 测度构建五步法**，把一段评论文本转化为能够进入计量模型的研究变量，并检验其信度、效度与解释力。

```
① 语料获取  →  ② 文本预处理  →  ③ 特征提取  →  ④ 指标构建  →  ⑤ 信效度检验
   Corpus        Preprocessing    Feature        Measure        Reliability &
 Acquisition                     Extraction     Construction      Validity
```

**核心研究问题**

1. 能否把中文评论**稳定地**转换为情感测度？
2. 该测度是否符合内容、聚合、区分、预测四类效度要求？
3. 情感倾向能否**显著预测**产品销量？
4. 该测度在**何种模型设定下会失效**？

## 二、关键结果一览

| 检验维度 | 核心指标 | 结果 | 判断 |
|---|---|---|---|
| 语料规模 | 真实标注评论 | **82,431 条** | 电商十品类 62,688 + 酒店 7,763 + 外卖 11,980 |
| 词典规模 | 三层来源词典 | **341 词** | 正向 154 / 负向 187 |
| 内容效度 | 极性判别准确率 | **85.7%**（电商）/ 85.2%（全样本） | 通过 |
| 聚合效度 | 与机器学习测度相关 | **r = 0.535\*\*\*** | 通过 |
| 聚合效度 | 与词嵌入测度相关 | **r = 0.609\*\*\*** | 通过 |
| 区分效度 | 与文本长度相关 | **r = −0.067** | 通过（弱相关） |
| 预测效度 | Logit 系数 | **β = 0.077, z = 125.61\*\*\*** | 通过 |
| 信度 | Cronbach's α | **0.825** | 通过（>0.7） |
| 主回归 | 混合 OLS 情感系数 | **0.0382\*\*\*** | 显著为正 |
| 主回归 | 组间估计系数 | **0.1225\*\*\*** | 显著为正 |
| 主回归 | 双向固定效应 | 0.0001（不显著） | **识别力边界** |
| 稳健性 | 安慰剂检验（置换500次） | **p < 0.002** | 通过 |

> **一个重要发现**：混合 OLS 与组间估计均显著，而双向固定效应模型下效应消失。
> 这**不是失败**，而是揭示了测度的适用边界——情感测度识别的是**产品间的稳定口碑差异**，
> 而非同一产品的**短期销量波动**。

## 五、方法要点

### 5.1 情感词典的三层来源（内容效度依据）

| 来源 | 说明 | 词数 |
|---|---|---|
| **A · 通用词表** | 中文情感分析常用种子词，人工归类 | 179 |
| **B · 语料 LLR 扩展** | 对数似然比在标注语料上筛选，词频≥60 | 162 |
| **C · 领域补充** | 电商/外卖/酒店场景特有表达 | 37 |

来源 B 的计算公式：

$$\text{LLR}(w) = \text{sign}(p_1 - p_0) \times 2\left[n_1 \ln\frac{p_1}{p_m} + n_0 \ln\frac{p_0}{p_m}\right]$$

> **为什么这样设计？** 避免"拍脑袋造词"的批评——词表既有理论支撑（来源A），
> 又有统计证据（来源B），还覆盖场景特征（来源C）。

### 5.2 情感得分计算（指标构建）

$$\text{Sentiment}_{it} = \frac{W_{pos} - W_{neg}}{N} \times 100$$

其中 $W_{pos}$、$W_{neg}$ 为**加权后**的正负情感词命中年（支持程度副词倍率与否定词极性翻转），
$N$ 为去停用词后的总词数。

### 5.3 测度的三个层次

| 层次 | 变量 | 说明 |
|---|---|---|
| **L1 原始计数** | L1_PosCnt / L1_NegCnt | 受篇幅影响，不直接使用 |
| **L2 标准化比率** | **L2_Sentiment_word** | 主测度，分母口径统一 |
| **L3 复合测度** | L3_Composite | 0.5×极性 + 0.3×强度 − 0.2×离散度 |
